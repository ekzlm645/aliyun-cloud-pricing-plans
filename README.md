阿里云无影云电脑个人版和企业版的计费方式完全不同：个人版按“核时”计费，买的是一份可以跨配置使用的算力配额，用多少核开机、开多久就从配额里扣；企业版按“时长包”计费，买的是某台固定规格云电脑每月的开机小时数，超出部分按量补钱，精品带宽、共享存储这类增值服务还要单独付费。顺带说一句，这份配额目前在官方个人版商品页写作“无影灵豆”，早期资料里叫“核时”，换算规则一样——1核时就是1个CPU核心开机1小时。

两个版本之间也没有互通通道：账号体系独立，个人版不能升级或转成企业版，反过来也不行。所以下单前搞清楚计费差异，比单纯比价更重要。

## 两套计费体系的核心区别

一句话概括：个人版买“配额”，企业版买“机器时长”。具体差异都在这张表里：

| 对比维度 | 个人版 | 企业版 |
| --- | --- | --- |
| 计费单位 | 核时/无影灵豆（CPU核数×小时数） | 时长包（每月小时数），另有按量付费 |
| 套餐形式 | 黄金款到黑金款五档，月卡/季卡/年卡 | 基础办公型、高级办公型、图形工作站等，按月或按年买时长包 |
| 额度怎么用 | 配额跟人走，可以跨配置：40核时=4核8G开机10小时=8核16G开机5小时 | 时长包绑定具体规格，机器开机就计时 |
| 额度有效期 | 当月有效，不可结转 | 时长包1个月有效，剩余时长不可转存次月 |
| 用超了怎么办 | 购买畅玩加油包补充 | 超出部分按需计费，当月消费封顶为该规格的目录月价 |
| 关机是否计费 | 关机不计费，存档保留 | 关机不计费，10分钟无连接自动关机/休眠 |
| 增值服务 | 套餐内含数据盘，基本一站式 | 精品带宽、NAS、AD对接、录屏审计等单独计费 |

个人版核时最大的特点是“跟人不跟机器”：同样40核时，今天用4核8G处理文档能开10小时，明天想用8核16G剪视频，就变成5小时。企业版则是先选定规格再买时长，规格固定。

## 算一笔账：同样的开机时长，两种计费差多少

按活动价折算，企业版每小时的成本低不少，但前提是你愿意走企业版的开通流程。以最常见的4核8G、每月开机约120小时（每天4小时左右）为例：

- 企业版：4核8G、120小时/月时长包，年付促销价199元，折合每月约16.6元；
- 个人版：4核8G开机120小时需要480核时，钛金款（320核时，79.9元/月）不够用，黑金款（640核时）149.9元/月，或者钛金款加2000核时加油包（63.7元/年）拼到约85元/月。

同样一台4核8G、每月120小时，企业版活动价折算下来大约是个人版的五分之一。差距来自几个方面：企业版这个价位属于活动特价；时长包绑定固定规格，不能像核时那样跨配置调剂；个人版的价格里也包含了“开箱即用”的部分——不用配置管理员和账号体系，客户端或小程序登录就能用。

反过来看，如果每月开机不超过10小时，个人版黄金款14.9元/月就够了，为省单价去开通企业版、设置管理员和员工账号，时间成本不划算。开机时长不稳定、经常换配置的用户也是同理，配额制的个人版更省心。

## 个人版还是企业版：按使用方式对号入座

判断标准其实就一条：这台云电脑给谁用、要不要管。

- 自己或家人用（网课、日常办公、给孩子当学习电脑）→ 个人版。一套阿里云账号，短信验证码或扫码登录，买完即用。
- 主要打游戏或做视频剪辑 → 个人版钛金款、黑金款打底，按需叠加油包。注意个人版只有Windows Server 2022镜像，个别依赖Win10环境或微软商店的软件装不了，C盘固定60GB，游戏和大文件放数据盘。
- 公司批量使用，需要固定出口IP、内网互通、AD/SSO、批量部署、防截屏水印和操作审计 → 企业版。管理员用阿里云账号，员工用分配的无影便捷账号，控制台统一管控。
- 建筑设计、影视后期、3D建模这类专业图形需求 → 企业版图形工作站，RTX 5880显卡，16核32G起。
- 流协同（多人实时协作）是企业版专属功能，个人版没有。

## 几个高频问题

**核时用完了怎么办？**
个人版当月只能靠加油包补；企业版不用管，超时后自动按需计费。

**关机了还扣费吗？**
不扣。个人版关机不计核时，企业版关机不计时长，存档和数据都保留。

**电竞模式一小时烧多少核时？**
60核时。黑金款640核时够玩10小时左右，重度游戏记得叠加油包。

**个人版能转成企业版吗？**
不能。官方明确两个版本不支持直接升级、补差价转换或切换。要用企业版功能只能单独购买实例，数据需要自行迁移。

**企业版时长包用超了账单会失控吗？**
不会。超出部分按需计费，但当月消费封顶为该规格的目录月价。
